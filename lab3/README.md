## Как работает программа

Программа повторяет ход ручного решения.

1. Находит нерегулярные точки — точки ограничений, в которых градиенты ограничений линейно зависимы.
2. Составляет функцию Лагранжа $L = f + \sum \lambda_i g_i$ и систему $\partial L/\partial x_j = 0,\ g_i = 0$, решает её
   точно и оставляет только вещественные решения.
3. Подставляет каждую найденную точку обратно в ограничения и в систему и проверяет, что они выполняются
   (с точностью 50 значащих цифр).
4. Определяет характер каждой регулярной точки по знаку второго дифференциала $d^2L$ на касательном подпространстве
   (это равносильно проверке окаймлённой матрицы Гессе): минимум, максимум, не экстремум или «второй порядок не даёт
   ответа».
5. Если допустимое множество ограничено, по теореме Вейерштрасса называет глобальные минимум и максимум.

Функция Лагранжа и производные строятся в [lagrange/method.py](lagrange/method.py) вручную. SymPy нужен только для
символьных вычислений и решения системы уравнений.

Результат для варианта 20:

```
f(x, y, z) = x + y + 2*z
g1 = x^2 + y^2 + z^2 - 5 = 0
g2 = x*z = 0
L = x + y + 2*z + λ1*(x^2 + y^2 + z^2 - 5) + λ2*(x*z)
Система ∂L/∂x = 0, g = 0:
  2*x*λ1 + z*λ2 + 1 = 0
  2*y*λ1 + 1 = 0
  x*λ2 + 2*z*λ1 + 2 = 0
  x^2 + y^2 + z^2 - 5 = 0
  x*z = 0

Точки (x, y, z), подозрительные на экстремум, по возрастанию f:
  (0, -1, -2): f = -5, λ = (1/2, 1/2)
      строгий локальный минимум
  (-sqrt(10)/2, -sqrt(10)/2, 0): f = -sqrt(10) ≈ -3.16228, λ = (sqrt(10)/10, 2*sqrt(10)/5)
      строгий локальный минимум
  (0, -sqrt(5), 0): f = -sqrt(5) ≈ -2.23607
      нерегулярная точка: метод Лагранжа её не классифицирует
  (0, sqrt(5), 0): f = sqrt(5) ≈ 2.23607
      нерегулярная точка: метод Лагранжа её не классифицирует
  (sqrt(10)/2, sqrt(10)/2, 0): f = sqrt(10) ≈ 3.16228, λ = (-sqrt(10)/10, -2*sqrt(10)/5)
      строгий локальный максимум
  (0, 1, 2): f = 5, λ = (-1/2, -1/2)
      строгий локальный максимум

Допустимое множество замкнуто и ограничено. По теореме Вейерштрасса f достигает на нём
наибольшего и наименьшего значений, и только в найденных точках:
  глобальный минимум f = -5 в (0, -1, -2)
  глобальный максимум f = 5 в (0, 1, 2)
```

## Ограничения

- Функция и ограничения должны быть многочленами (степень не выше 100). Для других функций система в общем случае
  не решается аналитически.
- Ограничений не больше, чем переменных; неравенства не поддерживаются.
- Нерегулярные точки программа находит, но их характер нужно исследовать отдельно: метод Лагранжа на них не
  распространяется. Для варианта 20 это сделано в отчёте.
- Ограниченность допустимого множества проверяется по достаточному признаку: одно из ограничений задаёт эллипсоид,
  или ограничений столько же, сколько переменных. Если признак не сработал, программа об этом сообщает, и вывод о
  глобальных экстремумах делается вручную.
- Если подозрительных точек бесконечно много (например, $f$ постоянна на части ограничения), программа выводит
  найденное семейство точек и не классифицирует его.
- Если система не решается за 60 секунд, вычисление прерывается с сообщением об ошибке.

При некорректном вводе программа объясняет, что не так, и завершается с кодом 2.
