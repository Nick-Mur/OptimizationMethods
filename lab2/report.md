## 1. Постановка задачи

Найти глобальный минимум (или максимум) липшицевой функции $W(x)$ на отрезке $[a,b]$ с точностью $\varepsilon$ по
значению функции:

$$W(x^*)-W^* < \varepsilon,\qquad W^*=\min_{x\in[a,b]}W(x).$$

Вход: строка функции, концы отрезка $a,b$, точность $\varepsilon$. Выход: $x^*$, $W(x^*)$, число итераций, время,
график функции, вспомогательных функций и итоговой ломаной.

## 2. Метод

Функция липшицева, если $|W(u)-W(v)|\le L|u-v|$ для всех $u,v\in[a,b]$.

Для каждой вычисленной точки $u_i$ строится вспомогательная функция

$$g_i(x)=W(u_i)-L|x-u_i|\le W(x),$$

а по ним ломаная

$$p_n(x)=\max_{i=0,\dots,n}g_i(x)\le W(x).$$

Итерации: $u_0=a$, $u_1=b$, далее $u_n=\arg\min\limits_{x\in[a,b]}p_{n-1}(x)$.

Минимум ломаной достигается в одной из нижних вершин. Для соседних точек $x_i < x_{i+1}$, $z_i=W(x_i)$, нижняя вершина —
пересечение $g_i$ и $g_{i+1}$:

$$u=\frac{x_i+x_{i+1}}{2}+\frac{z_i-z_{i+1}}{2L},\qquad p(u)=\frac{z_i+z_{i+1}}{2}-\frac{L(x_{i+1}-x_i)}{2}.$$

На каждой итерации считаю $p(u)$ во всех нижних вершинах и беру наименьшее. Разбиение отрезка для поиска минимума не
используется.

Остановка: $W(u_n)-p_{n-1}(u_n) < \varepsilon$. Так как $p_{n-1}\le W$, то $p_{n-1}(u_n)\le W^*$, поэтому для лучшей из
вычисленных точек $x^*$ выполнено $W(x^*)-W^* < \varepsilon$.

Если $L$ не задана, она оценивается как в Excel-файле курса: $L=1{,}2\cdot\max|\Delta W/h|$ на сетке из 10 000 шагов.

Максимум ищется как минимум $-W$.

## 3. Проверка на примере из Excel-файла

$$W(x)=0{,}5x+0{,}2\cos(3{,}14x)+0{,}2\sin(2\cdot3{,}14x),\qquad x\in[-2,1],\qquad L=2{,}1542997\ \text{(ячейка F30)}.$$

Оценка $L$ в программе совпадает с Excel.

$u_0=-2$, $W(u_0)=-0{,}798727$; $u_1=1$, $W(u_1)=0{,}299363$.

**Итерация 2.**

$$u_2=\frac{-2+1}{2}+\frac{-0{,}798727-0{,}299363}{2\cdot2{,}154300}=-0{,}754860,$$

$$p_1(u_2)=\frac{-0{,}798727+0{,}299363}{2}-\frac{2{,}154300\cdot3}{2}=-3{,}481131.$$

$W(u_2)=-0{,}320906$, $W(u_2)-p_1(u_2)=3{,}160226 > \varepsilon$.

**Итерация 3.** Нижние вершины слева и справа от $u_2$ равны $-1{,}901019$, беру левую:

$$u_3=\frac{-2-0{,}754860}{2}+\frac{-0{,}798727+0{,}320906}{2\cdot2{,}154300}=-1{,}488329.$$

## 6. Рефлективный вывод

Работа помогла понять, чем метод ломаных отличается от локальных методов: он не просто находит хорошую точку, а с
помощью константы Липшица доказывает, что на отрезке нет точки лучше с точностью ε. Сложнее всего было разобраться,
зачем нужна ломаная и почему следующая точка берётся в её самой низкой вершине, — помогли разбор на простом числовом
примере и сверка своих итераций с Excel-файлом курса.
