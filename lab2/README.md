```bash
python main.py "10 + x^2 - 10*cos(2*pi*x)" -5.12 5.12 0.01
python main.py "x + sin(3.14159*x)" -1.5 2.5 0.01 --max
python main.py "abs(x - 0.3)" -1 1 0.001 --L 1 --plot result.png
python -m pytest -q
```

```
python main.py "ФУНКЦИЯ" a b eps [--L L] [--max] [--max-iter N] [--plot ФАЙЛ]
```

| Аргумент     | Значение                                     |
|--------------|----------------------------------------------|
| `--L`        | константа Липшица (по умолчанию оценивается) |
| `--max`      | искать максимум                              |
| `--max-iter` | лимит итераций (по умолчанию 10000)          |
| `--plot`     | сохранить график в файл вместо окна          |

Если `--L` не указан, программа оценивает L по максимальному наклону между соседними узлами сетки с запасом 1,2.
Этот способ приведён в конспектах «23.09 Метод ломаных» и «24.09 Метод ломаных». Сетка применяется для оценки L;
вершины ломаной рассчитываются по формулам пересечения. Оценённая L не обязательно подходит для всего отрезка.

Статус в выводе: `eps` — точность достигнута; `max_iter` или `float_limit` — нет (лимит итераций или предел
точности double), тогда реальная погрешность не больше строки «Оценочный разрыв при выбранной L» — при условии,
что L подходит для всего отрезка.

Если глобальных минимумов несколько, выводится один из них: оценка относится к значению W(x*), а не к месту
минимума. Остальные видны на графике по скоплениям точек.

## Примеры

Разные функции:

| Команда | Результат |
|---|---|
| `python main.py "10 + x^2 - 10*cos(2*pi*x)" -5.12 5.12 0.01` | Растригин, 11 локальных минимумов: W(0) = 0 |
| `python main.py "-20*exp(-0.2*sqrt(x^2)) - exp(cos(2*pi*x)) + 20 + e" -5 5 0.01` | Экли, минимум в изломе: W(0) = 0 |
| `python main.py "sin(x) + sin(10*x/3)" 2.7 7.5 0.01` | W(5.1459) = −1.8996 |
| `python main.py "x*sin(x)" 0 10 0.01` | минимум на краю: W(10) = −5.44 |
| `python main.py "cos(x)" 0 4*pi 0.01` | два минимума (π и 3π), выводится один: W(π) = −1 |
| `python main.py "5" 0 1 0.01` | константа: W = 5 сразу |

Точность (Растригин на [−5.12, 5.12]):

| eps | Итераций |
|---|---|
| `0.1` | 105 |
| `0.01` | 201 |
| `0.001` | 497 |

Аргументы:

| Команда | Что показывает |
|---|---|
| `python main.py "x + sin(3.14159*x)" -1.5 2.5 0.01` | минимум: W(−0.6036) = −1.5511 |
| `python main.py "x + sin(3.14159*x)" -1.5 2.5 0.01 --max` | максимум на краю: W(2.5) = 3.5 |
| `python main.py "abs(x - 0.3)" -1 1 0.001 --L 1` | точная L: ответ за 2 итерации |
| `python main.py "10 + x^2 - 10*cos(2*pi*x)" -5.12 5.12 0.01 --L 1` | слишком маленькая L: ошибка |
| `python main.py "10 + x^2 - 10*cos(2*pi*x)" -5.12 5.12 0.000000001 --max-iter 20` | не хватило итераций: предупреждение |
| `python main.py "sqrt(x)" 0 1 0.01` | не липшицева функция: предупреждение |
| `python main.py "x^2" -1 1 0.01 --plot result.png` | график в файл `result.png` |

## Формат ввода

**Функция** от `x`: числа, `pi`, `e`, `+ - * / ^`, скобки, функции
`sin cos tan asin acos atan sinh cosh tanh exp log ln log10 sqrt abs`, `min(…, …)`, `max(…, …)`.
Можно с левой частью: `f(x) = …`. Умножение только явное: `2*x`, а не `2x`.

**Числа** (`a`, `b`, `eps`, `--L`) пишутся через точку: `0.01`, `-5.12`. Можно использовать `pi` и `e`: `-2*pi`, `pi/2`.

**Ошибка** (код выхода 2):

- в функции неизвестная переменная или функция, синтаксическая ошибка;
- функция не определена или бесконечна на отрезке (`log(x)` на [-1, 1], `1/x` через 0);
- a ≥ b, eps ≤ 0, L ≤ 0, `--max-iter` < 2;
- заданная L меньше наклона между вычисленными точками.

**Предупреждения**:

- «L увеличена до …» — L не задана, программа оценила её сама и потом нашла участок круче оценки. Она уже
  увеличила L, делать ничего не нужно;
- «оценка L зависит от шага сетки…» — функция где-то бесконечно крутая (например, `sqrt(x)` около 0), ответу
  нельзя полностью доверять;
- «точность eps не достигнута» — не хватило итераций. Увеличьте `--max-iter` или возьмите eps побольше.
