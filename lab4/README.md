## Запуск

Команды выполняются из каталога lab4. Python 3.11 или новее.
Для программы достаточно стандартной библиотеки; pytest нужен только для тестов.

    python main.py
    python main.py --brief
    python main.py --config task.json
    pip install -r requirements.txt
    python -m pytest -q

Ответ варианта 20: **(3, 2, 3)** пакета, результативность **36**.
Программа показывает исходные ограничения, таблицу Беллмана и восстановление плана.
Знак «—» обозначает недостижимое состояние. Флаг --brief скрывает таблицу.

## Свои данные

Пример содержимого task.json:

    {
      "budget": 3,
      "teams": [
        {"name": "А", "rewards": [0, 2, 4], "allowed": [1, 2]},
        {"name": "Б", "rewards": [0, 2, 4], "allowed": [1, 2]}
      ]
    }

budget — общий ресурс, rewards[u] — выигрыш при выделении u пакетов,
allowed — разрешённые объёмы. Необязательное поле title задаёт название.
В этом примере два оптимальных плана, (1, 2) и (2, 1), с выигрышем 6.

Поддерживаются отрицательные и дробные выигрыши, нулевой бюджет и несколько
оптимумов. Дроби можно задавать строками с точкой или запятой. Decimal обеспечивает
точное сложение. Сохраняются все лучшие управления; --plans N выводит до N планов
(1–1000, по умолчанию 20), общее количество вычисляется полностью.

## Ошибки и ограничения

JSON должен быть в UTF-8, BOM допустим; размер — до 2 МБ.
Проверяются обязательные поля, типы чисел, конечность значений, уникальность названий,
длины таблиц и разрешённые объёмы. Неизвестные поля и повторные ключи отклоняются.
Ошибки чтения файла и отсутствие допустимого плана сопровождаются объяснением.
Успех — код 0, ошибка — 2, прерывание с клавиатуры — 130.

Бюджет — целое число 0–1000, участников — от 1 до 50, значений в таблице — до 1001.
Выигрыши ограничены модулем 10¹⁰⁰ и 100 десятичными знаками.
Верхняя оценка числа переходов — 5 млн; более крупная задача отклоняется.
Большие таблицы не печатаются целиком; найденный план выводится всегда.
